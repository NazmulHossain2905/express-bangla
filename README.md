## 📖 পরিচিতি

**Express Bangla** এমন একটি ওপেন লার্নিং প্ল্যাটফর্ম, যেখানে Node.js-এর সবচেয়ে জনপ্রিয় ব্যাকএন্ড ফ্রেমওয়ার্ক **Express.js 5** শেখানো হয় সম্পূর্ণ **বাংলা ভাষায়** — Node.js 24 LTS, Express 5.3 ও TypeScript 7 অনুযায়ী হালনাগাদ করা কনটেন্টে।

প্রতিটি ধারণা বাংলা ব্যাখ্যা ও বাংলাদেশি পাঠকের চেনা কনটেক্সটে (পথের পাঁচালী, লালসালু, বিরিয়ানি অর্ডার!) শেখানো হয়। কোড উদাহরণ তিন ধাঁচে লেবেলসহ — **CommonJS**, **ES Modules** ও **TypeScript** — যাতে পুরনো প্রজেক্ট আর নতুন, দুই দুনিয়াতেই আপনি স্বচ্ছন্দ হন। আর এটা শুধু পড়ার সাইট নয় — সার্চ, লাইভ API প্লেগ্রাউন্ড, কুইজ আর প্রোগ্রেস ট্র্যাকিং সহ একটা পূর্ণাঙ্গ ইন্টারঅ্যাক্টিভ প্ল্যাটফর্ম।

## ✨ বৈশিষ্ট্যসমূহ

- 📚 **৪০টি গোছানো পাঠ** — ৭টি সেকশনে সাজানো: শুরু করা → মডিউল সিস্টেম → মূল ধারণা → অ্যাপ্লিকেশন তৈরি → প্রোডাকশন → TypeScript → API রেফারেন্স → গাইড
- 🔍 **ফুল-টেক্সট সার্চ** — `Ctrl+K` / `/` শর্টকাট; বাংলা ও ইংরেজি উভয় জিজ্ঞেস, ফাজি ম্যাচিং, heading-লেভেল নেভিগেশন, হাইলাইটেড স্নিপেট (MiniSearch + cmdk)
- 🔗 **প্রতিটি পাঠের নিজস্ব URL** — ডিপ-লিংক, ব্রাউজার ব্যাক/ফরোয়ার্ড, সোশ্যাল শেয়ার — সব কাজ করে
- 🏷️ **লেবেলড কোড উদাহরণ** — প্রতিটি কোড ব্লকে CJS/ESM/TS ব্যাজ, এক ক্লিকে কপি
- 🧪 **লাইভ প্লেগ্রাউন্ড** — ব্রাউজার থেকেই আসল Books CRUD API-তে GET/POST/PUT/DELETE
- 📝 **কুইজ** — প্রতিটি উত্তরের ব্যাখ্যাসহ
- ✅ **প্রোগ্রেস ট্র্যাকিং** — localStorage-এ অটো-সেভ
- 🌗 **ডার্ক ও লাইট মোড**, 📱 সম্পূর্ণ রেসপন্সিভ, ♿ কীবোর্ড-বান্ধব নেভিগেশন
- 🗺️ **SEO** — প্রতি পাতায় টাইটেল/ক্যানোনিকাল/OG মেটাডেটা, sitemap.xml, robots.txt, JSON-LD
- 🔤 **বাংলা-ফার্স্ট UI** — Noto Sans Bengali + JetBrains Mono

## 🚀 শুরু করুন

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/NazmulHossain2905/express-bangla.git
cd express-bangla

# ২. ডিপেন্ডেন্সি ইনস্টল করুন
npm install        # অথবা: bun install

# ৩. ডেভেলপমেন্ট সার্ভার চালু
npm run dev        # অথবা: bun dev
```

ব্রাউজারে যান: **http://localhost:3000** — `Ctrl+K` চেপে সার্চ চেষ্টা করে দেখুন!

### প্রোডাকশন বিল্ড

```bash
npm run build      # স্ট্যাটিক পেজ + standalone সার্ভার তৈরি
npm start          # প্রোডাকশন সার্ভার চালু (bun দিয়ে)
```

### স্ক্রিপ্টসমূহ

| কমান্ড | কাজ |
| --- | --- |
| `npm run dev` | ডেভেলপমেন্ট সার্ভার (পোর্ট 3000) |
| `npm run build` | প্রোডাকশন বিল্ড + standalone কপি |
| `npm start` | প্রোডাকশন সার্ভার চালু |
| `npm run lint` | ESLint যাচাই |

## 📁 প্রজেক্ট স্ট্রাকচার

```
express-bangla/
├── src/
│   ├── app/
│   │   ├── api/
│   │   │   ├── playground/route.ts   # লাইভ Books CRUD API
│   │   │   └── search-index/route.ts # সার্চ ইনডেক্স (build-time, স্ট্যাটিক)
│   │   ├── docs/[slug]/page.tsx      # প্রতিটি পাঠের SSG পেজ + মেটাডেটা
│   │   ├── playground/page.tsx       # ইন্টারঅ্যাক্টিভ প্লেগ্রাউন্ড
│   │   ├── quiz/page.tsx             # কুইজ
│   │   ├── layout.tsx                # ফন্ট, থিম, গ্লোবাল SEO
│   │   ├── sitemap.ts                # sitemap.xml জেনারেটর
│   │   └── not-found.tsx             # বাংলা 404
│   ├── components/course/            # কোর্স UI (shell, সার্চ, পাঠ ভিউ…)
│   ├── lib/
│   │   ├── course/                   # 📚 সম্পূর্ণ কনটেন্ট — সেকশন ফাইলে সাজানো
│   │   ├── search.ts                 # MiniSearch ইনডেক্স বিল্ডার
│   │   └── progress.ts               # localStorage প্রোগ্রেস স্টোর
├── examples/express5-verified/        # ডকুমেন্টেড কোডের লাইভ ভেরিফিকেশন
└── package.json
```

**নতুন পাঠ যোগ করার নিয়ম:** `src/lib/course/`-এ যেকোনো সেকশন ফাইলে `Lesson` অবজেক্ট যোগ করুন — রাউট, সাইডবার, সার্চ ইনডেক্স, sitemap, prev/next সবকিছু **স্বয়ংক্রিয়ভাবে** আপডেট হয়ে যাবে।

## ✅ কনটেন্ট ভেরিফিকেশন

এই ডকুমেন্টেশনের ভার্সন-দাবিগুলো শুধু লেখা নয় — চালিয়ে প্রমাণিত:

```bash
cd examples/express5-verified
node verify.mjs          # Express 5 আচরণ যাচাই (8টি চেক)
npx tsc --noEmit         # TypeScript উদাহরণ strict মোডে কম্পাইল-চেক
```

- Node.js LTS: **24.22.0 (Krypton)** — [nodejs.org](https://nodejs.org)
- Express.js: **5.3.0** (Node ≥18) — [expressjs.com](https://expressjs.com)
- TypeScript: **7.0.2** + @types/express **5.0.6**

## 🤝 কনট্রিবিউট করবেন যেভাবে

1. রিপোজিটরি **fork** করে নতুন ব্রাঞ্চ নিন: `git checkout -b feature/নতুন-পাঠ`
2. `src/lib/course/`-এর যেকোনো সেকশন ফাইলে পাঠ যোগ করুন (`Lesson` টাইপ মেনে)
3. কোড উদাহরণে `variant: "cjs" | "esm" | "ts"` লেবেল দিন
4. PR খুলুন — `tsc`, `eslint` ও বিল্ড সবুজ থাকতে হবে

**লেখার নিয়ম:** ব্যাখ্যা বাংলায়, টেকনিক্যাল টার্ম (middleware, route, endpoint) ইংরেজিতেই — বাংলা টেক-লেখার প্রচলিত রীতি অনুযায়ী।
