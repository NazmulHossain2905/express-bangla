## 📖 পরিচিতি

**Express Bangla** এমন একটি ওপেন লার্নিং প্ল্যাটফর্ম, যেখানে Node.js-এর সবচেয়ে জনপ্রিয় ব্যাকএন্ড ফ্রেমওয়ার্ক **Express.js** শেখানো হয়েছে সম্পূর্ণ **বাংলা ভাষায়**।

বেশিরভাগ বাংলা-ভাষী শিক্ষার্থীর কাছে ইংরেজি টিউটোরিয়াল অনুসরণ করা কঠিন — ভাষার বাধায় অনেকেই মাঝপথে থেমে যান। এই প্রজেক্টের লক্ষ্য সেই বাধা দূর করা। এখানে প্রতিটি ধারণা — সার্ভার কী, রাউট কীভাবে কাজ করে, মিডলওয়্যার কেন দরকার — সবই ব্যাখ্যা করা হয়েছে সহজ, ঘরোয়া বাংলায়, সাথে রিয়েল-লাইফ উদাহরণ আর বাঙালি পাঠকের চেনা কনটেক্সট (পথের পাঁচালী, লালসালু, পদ্মা নদীর মাঝি — এমনকি বিরিয়ানি অর্ডারও!)।

আর এটা শুধু পড়ার সাইট নয় — এটা একটা **ইন্টারঅ্যাক্টিভ** প্ল্যাটফর্ম। লেসন পড়ার পর সরাসরি ব্রাউজার থেকেই REST API-তে রিকোয়েস্ট পাঠানো যায়, কুইজে নিজের শেখা যাচাই করা যায়, আর প্রোগ্রেস অটো-সেভ হতে থাকে।

## ✨ বৈশিষ্ট্যসমূহ

- 📚 **১২টি হাতে-কলমে লেসন** — পরিচিতি থেকে REST API পর্যন্ত ধাপে ধাপে, প্রতিটি লেসনে ব্যাখ্যা + কোড + আউটপুট
- 🧪 **লাইভ প্লেগ্রাউন্ড** — কিছু ইনস্টল না করেই ব্রাউজার থেকে আসল REST API (Books CRUD) টেস্ট; প্রতিটি রিকোয়েস্টের সমতুল্য Express কোডও দেখা যায়
- 📝 **১০টি প্রশ্নের কুইজ** — প্রতিটি উত্তরের ব্যাখ্যাসহ; স্কোর বাংলা সংখ্যায়
- 📋 **Express চিটশিট** — সব গুরুত্বপূর্ণ কমান্ড ও কোড এক জায়গায়
- ✅ **প্রোগ্রেস ট্র্যাকিং** — কোন লেসন শেষ হয়েছে তা localStorage-এ সেভ হয়; সাইডবারে শতকরা অগ্রগতি দেখা যায়
- 🌗 **ডার্ক ও লাইট মোড** — সিস্টেম থিম অনুসরণ করে, যেকোনো সময় সুইচ করা যায়
- 📱 **সম্পূর্ণ রেসপন্সিভ** — মোবাইল, ট্যাব ও ডেস্কটপে সমান অভিজ্ঞতা; মোবাইলে শিট-স্টাইল মেনু
- 🎨 **সিনট্যাক্স হাইলাইটিং** — Prism ভিত্তিক কোড হাইলাইট, এক ক্লিকে কপি বাটন ও আউটপুট প্যানেল
- 🔤 **বাংলা-ফার্স্ট UI** — Noto Sans Bengali ফন্ট, বাংলা সংখ্যা, `lang="bn"`

## 🚀 শুরু করুন

### প্রয়োজনীয় সফটওয়্যার

- **Node.js 18 বা তার উপরের ভার্সন** (npm সহ) — অথবা **Bun 1.x**
- ইন্টারনেট কানেকশন (প্রথমবার প্যাকেজ ইনস্টলের সময়)

### ইনস্টলেশন ও চালানো

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/NazmulHossain2905/express-bangla.git
cd express-bangla

# ২. ডিপেন্ডেন্সি ইনস্টল করুন
npm install
# Bun ব্যবহার করলে: bun install

# ৩. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

এবার ব্রাউজারে যান: **http://localhost:3000** 🎉

## 🧪 লাইভ প্লেগ্রাউন্ড API

সাইডবারের "প্লেগ্রাউন্ড" ট্যাবে গেলে লেসনে শেখা প্রতিটি HTTP মেথড নিজে হাতে টেস্ট করা যায়। ব্যাকএন্ডের `/api/playground` রুটটি একটি **Express-স্টাইল Books CRUD API** ইমুলেট করে — সঠিক HTTP স্ট্যাটাস কোডসহ (200 / 201 / 204 / 400 / 404)।

- **ডেটা মেমোরিতে রাখা হয়**, তাই সার্ভার রিস্টার্ট হলে ডেটা রিসেট হয়ে যায় (প্র্যাকটিস সহজ রাখার জন্য এটা ইচ্ছাকৃত)
- প্লেগ্রাউন্ড UI-তে প্রতিটি রিকোয়েস্টের পাশে **সমতুল্য Express কোড** দেখা যায় — অর্থাৎ ব্রাউজারে যা করছেন, সেটাই পরে `app.get()` / `app.post()` দিয়ে করবেন
- রিকোয়েস্ট হিস্ট্রি সেভ হয়, তাই আগের টেস্টগুলো ফিরে দেখা যায়

চাইলে curl বা Postman দিয়েও টেস্ট করতে পারেন:

```bash
# সব বইয়ের তালিকা দেখুন
curl "http://localhost:3000/api/playground?target=/books"

# ২ নম্বর বই দেখুন
curl "http://localhost:3000/api/playground?target=/books/2"

# নতুন বই যোগ করুন
curl -X POST "http://localhost:3000/api/playground?target=/books" \
  -H "Content-Type: application/json" \
  -d '{"title": "আমার প্রথম API", "author": "আপনার নাম", "year": 2026}'
```

সফল `POST` রিকোয়েস্টে রেসপন্স আসবে `201 Created` স্ট্যাটাসসহ; `title` বা `author` বাদ দিলে আসবে `400 Bad Request` — ঠিক যেমনটা লেসন ৯-এ শেখা হয়।

## 🎯 কীভাবে শিখবেন (শেখার পথনির্দেশ)

1. **ল্যান্ডিং পেজ থেকে শুরু করুন** — "শুরু করুন" বাটনে ক্লিক করলেই প্রথম লেসনে চলে যাবেন
2. **লেসন পড়ুন, কোড চালিয়ে দেখুন** — প্রতিটি লেসনে ব্যাখ্যা, কোড উদাহরণ ও আউটপুট আছে; কোড কপি করে নিজের কম্পিউটারে রান করুন
3. **প্লেগ্রাউন্ডে প্র্যাকটিস করুন** — REST API লেসন পড়ার পর লাইভ প্লেগ্রাউন্ডে নিজে রিকোয়েস্ট পাঠিয়ে স্ট্যাটাস কোড পর্যবেক্ষণ করুন
4. **কুইজে যাচাই করুন** — সব লেসন শেষে ১০টি প্রশ্নের কুইজ দিয়ে নিজের প্রস্তুতি মাপুন
5. **চিটশিট হাতের কাছে রাখুন** — প্রজেক্ট করার সময় এক নজরে সব কমান্ড বের করুন

## 🤝 কনট্রিবিউট করবেন যেভাবে

কনটেন্টে ভুল পেলে, বানান ঠিক করতে চাইলে, বা নতুন লেসন যোগ করতে চাইলে সাদরে স্বাগত!

1. এই রিপোজিটরি **fork** করুন
2. নতুন ব্রাঞ্চ তৈরি করুন:
   ```bash
   git checkout -b feature/নতুন-লেসন
   ```
3. পরিবর্তন **commit** করুন:
   ```bash
   git commit -m "লেসন ১৩: authentication যোগ করা হয়েছে"
   ```
4. ব্রাঞ্চে **push** করুন: `git push origin feature/নতুন-লেসন`
5. GitHub-এ **Pull Request** খুলুন

**কনটেন্ট যোগ করার নিয়ম:**

- সব লেসন `src/lib/course/types.ts`-এর `Lesson` টাইপ অনুসরণ করে — নতুন লেসন ফাইল বানিয়ে `index.ts`-এ ইমপোর্ট করলেই সাইডবারে অটোমেটিক দেখা যাবে
- প্রযুক্তিগত শব্দ (middleware, route, endpoint ইত্যাদি) বাংলা টেক-লেখার প্রচলিত রীতি অনুযায়ী ল্যাটিন বর্ণেই রাখা হয়েছে — নতুন লেসনেও একই রীতি মেনে চলুন
- কোড উদাহরণে বাঙালি পাঠকের চেনা নাম ও কনটেক্সট ব্যবহার করার চেষ্টা করুন
